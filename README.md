# 🛒 E-Commerce Sales & Promotion Analysis

## 🎯 OBJECTIVE

* Analyze overall user activity and engagement across the e-commerce platform.
* Identify high-performing products and categories based on user activity.
* Analyze user activity across different channels and locations.
* Identify peak days and time of user activity.
* Analyze product prices and user scores to identify relevant patterns.
* Examine promotional activity and discounts across products.
* Generate business insights using Excel, SQL, and Power BI to support data-driven decision-making.

## 🛠️ TOOL USED

Microsoft Excel, MySQL, Power BI

## 📊 DATASET DESCRIPTION

The e-commerce sales dataset contains customer interactions, user score, product details and user activities across different dates, days, channels, and locations. The promotion dataset contains product IDs, promotion IDs, date on which the promotion was applied, along with the percentage of discount applied to each product.

## 📑 DATA PREPERATION USING EXCEL

Before analysing the data, the dataset was prepared in Excel. Initially, the dataset was reviewed to understand the columns and data types. The date, time, currency, and number columns were then formatted appropriately. The data was also checked for duplicate records and inconsistencies to ensure it was ready for analysis. After the preparation process, Excel was used for basic data analysis.

## 🐬 MySQL ANALYSIS

The prepared dataset was then imported into MySQL for detailed analysis. SQL queries were used to explore the data and answer different business questions related to user activity, product and category performance, user behaviour, sales patterns, channel performance, and peak activity periods. Functions and techniques such as count, distinct, sum, avg, group by, order by, lag, data type conversion, joins, subqueries, dense_rank, and filtering conditions were used to analyse the data and identify meaningful patterns and insights.

## 📈 POWER BI ANALYSIS

The analysed data was then used in Power BI to create interactive dashboards and visualizations. KPI cards, funnel conversion chart, promotional effect matrix, channel distribution chart, time-series line graph was used to understand customer behaviour and business performance. Field parameters were also created to make the charts dynamic, allowing users to select different fields for the X and Y axes. Interactive slicers for states, days of the week, and event types were implemented making it easier to identify trends, compare performance, and present the findings in a clear and interactive way.

* Analyzing user engagement across different days, times, channels, and event types.
* Identifying popular products and analyzing product-level engagement and performance.
* Comparing performance and activity across different product categories, sub-categories and brands.
* Examining user activity and engagement patterns to understand customer behaviour.
